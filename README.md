| Layer | Technology |
|---|---|

| ML Models | Logistic Regression, SVM, Random Forest, XGBoost, KNN, LightGBM, Gradient Boosting, Naive Bayes |
| Tuning | SMOTE, GridSearchCV |
| Ensembling | Voting & Stacking Classifiers |
